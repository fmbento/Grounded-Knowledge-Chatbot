**Marcação semântica**  
Quando se produz um documento Word, por exemplo, marcam-se diferentes
elementos do texto criando uma camada de informação designada por **marcação
semântica**. Esta identifica os diferentes elementos que compõem o documento:
cabeçalhos, texto alternativo das imagens, hiperligações, tabelas, etc. Ao
converter-se um documento Word em PDF, deve manter-se toda esta estrutura.

Permite a um utilizador que usa tecnologias de apoio como o leitor de ecrã
navegar no documento em Pdf através dos cabeçalhos ou ter acesso ao conteúdo
de uma imagem. A não marcação do documento implica que o mesmo se apresente às
tecnologias de apoio, como se de um texto não estruturado se tratasse.

**Para converter um documento Word com marcação semântica em PDF, deve
efetuar-se os seguintes passos:**

1\. No documento Word, clicar no separador “File” e selecionar a opção “Save
as”  
2\. Clicar no campo “Save as type” e selecionar PDF  
3\. Clicar no botão “Options” e ativar as seguintes opções:

  * Create bookmarks using: Headings
  * Document properties
  * Document structure tags for accessibility

4\. Clicar no botão OK e, de seguida, em “Save”.

[Check Accessibility do Adobe Acrobat
Pro](https://helpx.adobe.com/acrobat/using/create-verify-pdf-
accessibility.html)  
O Adobe Acrobat Pro possui uma ferramenta "Check accessibility" que verifica
se o documento está em conformidade com os padrões de acessibilidade, como PDF
/ A e WCAG 2.1.

Após efetuar a verificação completa, os resultados são apresentados e
indicadas hiperligações e dicas úteis para solucionar os problemas
identificados.  
  
Permite analisar a acessibilidade do documento PDF e corrigir eventuais erros.
Exemplos:

  * efetuar o reconhecimento ótico de caracteres (OCR)
  * definir o idioma do documento
  * identificar imagens sem texto alternativo.
