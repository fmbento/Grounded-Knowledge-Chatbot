## Metadados genéricos e de citação

O DUnAs apresenta, por defeito, um esquema de representação composto por um
conjunto genérico/interdisciplinar de campos para a inserção dos metadados
considerados necessários para a descrição do dataset, designado por “Metadados
de Citação”. Este conjunto contém campos de preenchimento obrigatório e outros
de preenchimento recomendado.

Informação detalhada sobre cada um dos campos de metadados do bloco “Citation
Metadata” em:

  * [__metadados_bloco_citation_metadata](https://uapt.libguides.com/ld.php?content_id=35610032)

## Metadados específicos e disciplinares

Para além do esquema de metadados obrigatório e genérico, quando se cria ou
edita uma coleção Dataverse, é possível selecionar outros conjuntos de
metadados de cariz disciplinar/temático, estando disponíveis os seguintes:

  * Geospatial Metadata 

  * Social Science and Humanities Metadata 

  * Astronomy and Astrophysics Metadata 

  * Life Sciences Metadata 

  * Journal Metadata 

Os campos adicionados ficarão disponíveis para preenchimento após o dataset
ser criado e guardado a primeira vez.

## Personalização dos campos de metadados

No caso de uma unidade ou projeto de investigação necessitar da inclusão de um
conjunto de metadados específico de uma disciplina ou área de investigação
para a descrição dos seus dados, deverá contactar a equipa de [helpdesk do
DUnAs](mailto:sbidm-dunas@ua.pt) para que essa possibilidade seja avaliada.

Em qualquer dos conjuntos de metadados já disponíveis no repositório é
possível esconder campos que não se considerem relevantes no contexto de uma
determinada coleção Dataverse, assim como definir campos como obrigatórios ou
opcionais.

Para além da customização a este nível, é também possível a criação de
templates para os datasets de uma determinada coleção Dataverse,
possibilitando a existência de campos pré-preenchidos e a indicação de
instruções aos depositantes de como preencher determinados campos.

Assim que um dataset é publicado, os seus metadados poderão ser exportados em
vários standards e formatos, nomeadamente: Dublin Core, DDI, DataCite, JSON e
OpenAIRE.

## Workflow de depósito, curadoria de metadados e publicação

O fluxo de trabalho do repositório DUnAs organiza-se em três etapas
principais:

![](https://dkou0skpxpnwz.cloudfront.net/accounts/130855/images/workflow.png)

  
  
**Curadoria e depósito de dados**

O depósito de dados no repositório é efetuado pelos investigadores, mediante a
atribuição de permissões pelo administrador da coleção Dataverse ou do
dataset. Durante a fase de edição (inserção de metadados e carregamento de
ficheiros), o dataset permanece numa versão draft, não estando visível ao
público.

Quando o processo de criação e edição do dataset fica concluído, com todos os
metadados e ficheiros inseridos, o mesmo deverá ser submetido para revisão
(botão ‘Submeter para revisão’). A partir deste momento, o dataset fica
bloqueado, não permitindo qualquer adição ou alteração aos seus conteúdos por
parte dos depositantes.

**Curadoria de metadados**

Quando um dataset é submetido para revisão, a equipa da Biblioteca recebe uma
notificação e efetua a validação dos respetivos metadados. Se os metadados
estiverem corretos e completos, o dataset é publicado e o depositante é
notificado. Caso o dataset não respeite os critérios estabelecidos na
[política de depósito no DUnAs](https://www.ua.pt/file/70187) ou tenha
metadados incorretos ou em falta, a equipa da Biblioteca devolve o dataset ao
depositante para que sejam realizadas as alterações necessárias. Após a
realização destas alterações, o dataset deverá ser novamente submetido para
revisão e o procedimento segue o fluxo já descrito.

**Publicação do dataset**

Todos os datasets que passam o processo de revisão são publicados pela equipa
da Biblioteca e os respetivos DOI ficam automaticamente ativos.

Os depositantes poderão em qualquer momento modificar e acrescentar metadados
e ficheiros a um dataset, mesmo após a sua publicação. Estas alterações
originarão uma nova versão do dataset (que também deverá ser submetida para
revisão e, posteriormente, publicada pela equipa da Biblioteca). Após a
publicação de uma nova versão de um dataset, as versões anteriores continuam
disponíveis ao público, sendo mantido um histórico.

## Como criar um dataset no DUnAs

  * Entrar no repositório com as respetivas credenciais de acesso. 

  * Aceder à coleção Dataverse onde se pretende depositar os dados 

  * O pivot de dados da UI cria antecipadamente a subcoleção referente ao projeto de investigação e atribui as devidas permissões ao gestor de dados do projeto ou diretamente aos depositantes. 

  * Clicar no botão “Adicionar Dados” e depois em “Novo Dataset” 

  * Na criação de um novo dataset é apresentado um conjunto genérico de campos para a inserção dos metadados considerados necessários para a descrição do dataset, designado por “Metadados de Citação”. Desse conjunto de campos, destacam-se os campos obrigatórios, assim como outros cujo preenchimento é recomendado. Posteriormente, após o dataset ser guardado pela primeira vez, é possível aceder a mais campos para a descrição do dataset através dos botões ‘Editar’ > ‘Metadados’ (tanto do bloco ‘Metadados de Citação’ como de outros blocos de metadados que tenham sido selecionados nas configurações da coleção Dataverse de origem). 

  * Informação detalhada sobre cada um dos campos de metadados do bloco “Citation Metadata” em:

  * [__metadados_bloco_citation_metadata](https://uapt.libguides.com/ld.php?content_id=35610032)

## Como criar um modelo de dataset

Os modelos são úteis nos casos em que vários datasets têm a mesma informação
em vários campos de metadados. Com a utilização de modelos, quando se cria um
novo dataset, alguns campos já aparecem preenchidos, não sendo necessário
digitar tanta informação manualmente.

Os modelos são criados ao nível da coleção Dataverse, através dos seguintes
passos:

1\. Entrar na coleção Dataverse para a qual se pretende criar um modelo;

2\. Clicar no botão ‘Editar’ e depois em ‘Modelos de Dataset’;

3\. Clicar no botão ‘+ Criar Modelo de Dataset’;

4\. Preencher o campo ‘Nome do Modelo’ e todos os campos de metadados que são
comuns aos vários datasets;

5\. Terminar clicando no botão ‘Guardar + Adicionar Termos’;

6\. Na página que surge dedicada aos termos de uso e acesso, preencher os
campos pretendidos/aplicáveis aos datasets a serem depositados;

7\. Terminar clicando no botão ‘Guardar Modelo de Dataset’;

8\. Na página que se segue é possível gerir os modelos de dataset já criados
na coleção, cada um com as opções para tornar predefinido, ver, copiar, editar
e eliminar.
