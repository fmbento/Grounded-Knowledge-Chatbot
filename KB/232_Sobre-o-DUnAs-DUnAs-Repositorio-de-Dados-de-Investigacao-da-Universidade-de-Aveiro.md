## Apresentação

![](https://dkou0skpxpnwz.cloudfront.net/accounts/130855/images/BANNER_2.png)

[https://dunas.ua.pt/ ](https://dunas.ua.pt/)

O [DUnAs](https://dunas.ua.pt/) é o repositório de dados de investigação da
Universidade de Aveiro. Este repositório destina-se ao arquivo, publicação e
acesso aos dados de investigação gerados e recolhidos no âmbito das atividades
de investigação científica da Universidade.

O repositório DUnAs encontra-se implementado com base no software open source
[Dataverse](https://dataverse.org/), que é desenvolvida por uma comunidade
internacional liderada pela Universidade de Harvard.

## Objetivos

  1. Arquivar, preservar e partilhar os dados de investigação resultantes das atividades de investigação científica da Universidade de Aveiro. 
  2. Promover o acesso e a reutilização dos dados científicos. 
  3. Garantir a pesquisa e a recuperação dos dados arquivados. 
  4. Apoiar no cumprimento dos requisitos das agências financiadoras, nomeadamente da Comissão Europeia e da Fundação para a Ciência e a Tecnologia. 
  5. Atribuir um identificador único (DOI) a cada conjunto de dados, facilitando a sua citação.
  6. Facilitar a disponibilização de dados associados a publicações científicas, quer durante o processo de publicação (a editores/revisores), quer após.

## O que é um repositório de dados

É uma plataforma que permite que os dados de investigação sejam:

  * Depositados e descritos
  * Arquivados e preservados
  * Partilhados e publicados
  * Descobertos e reutilizados

## Características do software Dataverse

  * é um sistema open source de uso generalizado e com uma comunidade ativa; 

  * está desenhado especificamente para a partilha, preservação, citação, análise e disseminação de dados de investigação; 

  * suporta a atribuição automática de um identificador único e persistente a cada dataset e ficheiro publicado (DOI); 

  * contém esquemas de metadados genéricos (metadados de citação) e disciplinares/específicos (Geospatial; Social Science & Humanities; Astronomy and Astrophysics; Life Sciences; Journal); 

  * apresenta grande flexibilidade na definição de papéis e permissões dos utilizadores numa determinada coleção Dataverse, dataset e/ou ficheiro; 

  * possibilita a associação de uma [licença Creative ](https://creativecommons.org/share-your-work/cclicenses/)[Commons](https://creativecommons.org/share-your-work/cclicenses/) e a definição de termos de uso personalizados; 

  * permite a aplicação de diferentes níveis de acesso aos ficheiros depositados num dataset (aberto, embargado, restrito ou fechado); 

  * possibilita a ativação de uma funcionalidade para a recolha de dados sobre os utilizadores que fazem download dos ficheiros (Livros de visitas / Guestbooks); 

  * permite a partilha de um dataset antes do mesmo estar publicado, através de um URL privado; 

  * gere automaticamente as mudanças e o histórico das versões de um dataset (versionamento); 

  * recolhe estatísticas e métricas de uso (número de visualizações, downloads e citações). 

## Estrutura e organização

A estrutura do DUnAs foi projetada tendo em conta dois pressupostos
essenciais:

**2\. A ESTRUTURA ORGÂNICA DA UNIVERSIDADE DE AVEIRO**

O repositório irá contemplar uma coleção por cada unidade de investigação,
departamento, escola e serviço (sempre que se justifique). Dentro de cada uma
destas coleções principais serão criadas outras coleções que servirão para
organizar os conjuntos de dados associados às mesmas, de acordo com as suas
lógicas, formas de organização e estrutura.

Com base nestes dois pressupostos, a estrutura do DUnAs assenta tipicamente em
quatro níveis, por ordem crescente de granularidade:

Nível 1: Unidades de investigação e departamentos.

Nível 2: Projetos de investigação.

Nível 3: Conjuntos de dados relativos a um projeto de investigação.

Nível 4: Ficheiros que compõem um conjunto de dados.
