# Mendeley Reference Manager - Gestores de referências bibliográficas
## Nova versão Desktop

Atualmente, o Mendeley disponibiliza 2 versões desktop: Mendeley Desktop e****
Mendeley Reference Manager Desktop. A última versão do Mendeley Desktop
(1.19.8) não terá mais atualizações uma vez que foi substituída pelo
[Reference Manager Desktop](https://www.mendeley.com/guides/mendeley-
reference-manager/), versão que ainda se encontra em fase de testes podendo
apresentar ainda algumas limitações. O Mendeley Support Center está a avaliar
o feedback dos utilizadores relativamente a esta mudança e assim que for
decidida a migração definitiva, será feita a divulgação.  
  
Nota: depois de instalado o Reference Manager, os registos bibliográficos já
existentes no Mendeley Desktop migram automaticamente para esta nova versão.

## Plugin Mendeley Cite

O Mendeley Cite é o plugin que permite integrar citações e referências
bibliográficas da nova versão Mendeley Reference Manager no _MS-Word_ ou outro
processador de texto.  
  
**Instalação**  
1.**** No Mendeley Reference Manager Desktop:  
2\. Aceder ao Menu "Tools" e clicar na opção "Install Mendeley Cite for
Microsoft Word"

![](https://libapps-
eu.s3.amazonaws.com/accounts/49598/images/instalar_mendeley_cite_desktop.png)

  
3\. Na página [Microsoft AppSource](https://appsource.microsoft.com/en-
US/product/office/wa104382081), clicar em _Get it Now_ (não é necessário a
colocação de email):

![](https://libapps-
eu.s3.amazonaws.com/accounts/49567/images/app_mendeley_cite.png)

  
**Ativação do Suplemento**  
Se o plugin Mendeley Cite não estiver visível na barra de ferramentas do _MS-
Word ,_ é necessário ativar o suplemento:

1\. Menu Inserir ou Insert > Meus Suplementos ou My Add-ins  
2\. Na janela seguinte, selecionar o plugin Mendeley Cite e clicar em Inserir.  
3\. Verificar no canto superior lado direito da barra de ferramentas se a
caixa Mendeley Cite já se encontra visível.

Vídeo disponibilizado no Youtube pela Elsevier
